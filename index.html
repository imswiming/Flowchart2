Cloud Sync (Supabase)
Free tier, generous limits. Create a project at supabase.com/dashboard, then in the SQL Editor run: 
create table flowchart_sync (
  id text primary key,
  updated_at bigint,
  data jsonb
);
alter table flowchart_sync enable row level security;
create policy "allow all" on flowchart_sync
  for all using (true) with check (true);
Then go to Project Settings > API, copy the Project URL and the anon public key below, and click "Create New Sync" once. Enter the same URL, key, and Sync ID on your other devices to sync between them.
How to use this app
Building the tree
  • Tap/click a node to open its edit popup and type a name.
  • Use the radial buttons around a selected node to add a child, a sibling before/after it, or a parent above it.
  • Drag a node (hold Ctrl while dragging on desktop) to move it under a different parent.
  • Double-click a node with children to collapse/expand that branch.
  • The small grey stub at the end of a row of siblings is a placeholder - click it to turn it into a real node. Toggle "Hide Placeholders" (👻) to hide/show these stubs everywhere.
Node colors
  • Green - a solution/idea node. If it's a leaf (no children), it's automatically tagged "(Simplify?)" and gets guided Simplify questions in the left panel.
  • Pink - an Assumption node. Gets guided Assumption questions in the left panel to help you challenge it.
  • Blue / Yellow / Empty (grey) - general-purpose colors with no special behavior, useful for your own categorization.
Layout controls (bottom/top button row)
  • Top-Down / Left-Right - switches whether the tree grows downward or rightward.
  • Centered / Indented Layout - Centered balances siblings symmetrically like a classic org chart; Indented lists them like an outline, with the first child continuing in line with its parent.
  • Reset View - re-fits and centers the whole tree in the window.
  • Scroll/pinch to zoom, drag the background to pan.
  • As you pan, a parent whose position scrolls out of view "docks" to the edge of the screen as long as one of its children is still visible, so you don't lose track of which branch you're looking at.
Questions / Pugh Matrix / Notes panel
  • Questions tab shows guided prompts for the selected Assumption/Simplify node.
  • Pugh Matrix tab is a weighted-scoring decision matrix - add criteria, set weights, and score your options; a total weighted score is calculated per option.
  • Notes is a persistent bulleted outline, always visible under whichever tab is open. Press Tab/Shift+Tab, or Space/Backspace right at the start of a bullet, to indent/outdent. Space on a blank line creates a bullet; Backspace on a bullet's leftmost level removes just the bullet.
  • Use the +/- buttons in the panel header to zoom the panel's text and tables in or out.
Saving, sharing, and AI
  • Open - browse and load previously saved flowcharts (also lets you export/import as JSON files).
  • Export to AI / Import from AI - copies your tree as a plain-text outline (with a short explanation of its format) that you can paste to an AI assistant to discuss, restructure, or expand, then paste its response back in to rebuild the tree.
  • Cloud Sync - optional, uses your own free Supabase project to sync one flowchart between devices via a shared Sync ID.
  • Undo/Redo cover all tree edits; your work also autosaves locally as you go.
